Nosso objetivo é reter dados pessoais apenas pelo tempo razoavelmente necessário para a finalidade para a qual foram coletados, incluindo requisitos comerciais legítimos, de segurança, contábeis e legais. Os períodos publicados devem corresponder aos processos reais de exclusão e backup.

### Períodos de retenção

Os seguintes períodos e critérios aplicam-se aos sistemas do site descritos neste aviso:

| Dados | Implementação atual ou período proposto |
| --- | --- |
| Jornada do banco de dados VJT baseada em consentimento | padrão 90 dias |
| Intenção de evento de contato por WhatsApp/e-mail | padrão 90 dias |
| Resultado da consulta confirmado pelo servidor | padrão 730 dias |
| Cookie de visitante VJT | Até aproximadamente 365 dias |
| ID de visitante VJT no armazenamento local | Até que o consentimento para análise seja retirado ou o armazenamento do navegador seja limpo |
| Log JSON de e-mail de consulta | Últimos 1.000 registros em vez de um período baseado em tempo |
| Arquivos de fallback de limite de taxa | Contadores expirados são filtrados quando reutilizados, mas arquivos antigos podem permanecer |
| Caixa de correio de e-mail e correspondência comercial | Durante a consulta ou relação comercial e, depois, conforme exigido por necessidades contratuais, contábeis, de resolução de disputas e legais |
| Logs de servidor e backups | Conforme necessário para investigações de segurança e rotação de backups; depois, excluídos ou sobrescritos |

Os dados podem ser retidos por mais tempo quando razoavelmente necessário para uma obrigação legal, disputa, investigação de fraude ou reivindicação legal.

### Segurança

Usamos medidas técnicas e organizacionais destinadas a proteger dados pessoais contra acesso não autorizado, perda, uso indevido, alteração ou divulgação. As medidas podem incluir controles de acesso, interfaces administrativas protegidas, criptografia de transporte, limitação de taxa, verificação de segurança, armazenamento de servidor restrito e manutenção do sistema.

Nenhum método de transmissão ou armazenamento é completamente seguro.

Se um incidente de segurança afetar dados pessoais, a Kssmi deverá seguir um procedimento interno de avaliação e notificação que reflita os requisitos legais aplicáveis.
