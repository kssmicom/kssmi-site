We retain personal data only for as long as reasonably necessary for the purpose for which it was collected, including legitimate business, security, accounting and legal requirements.

### Retention schedule

The following periods and criteria apply to the website systems described in this notice:

| Data | Retention period or criterion |
| --- | --- |
| Consent-based VJT database journey | Normally 90 days, subject to the configured retention setting and automated cleanup |
| WhatsApp/email contact-event intent | Normally 90 days |
| Server-confirmed inquiry outcome | Normally 730 days |
| VJT visitor identifier in browser storage | Cookie up to approximately 365 days; local-storage copy until analytics consent is withdrawn or browser storage is cleared |
| Inquiry delivery log | Capped at the most recent 1,000 delivery records |
| Rate-limit and security counters | For the active security window and subsequent technical cleanup |
| Email mailbox and business correspondence | For the duration of the inquiry or business relationship and thereafter as needed for contracts, accounting, disputes and legal obligations |
| Server logs and backups | According to security investigation and backup-rotation needs, then deleted or overwritten when no longer necessary |

Data may be retained longer where reasonably necessary for a legal obligation, dispute, fraud investigation or legal claim. It may be deleted or anonymised earlier where it is no longer needed.

### Security

We use technical and organisational measures intended to protect personal data against unauthorised access, loss, misuse, alteration or disclosure. Measures may include access controls, protected administrative interfaces, transport encryption, rate limiting, security verification, restricted server storage and system maintenance.

No transmission or storage method is completely secure, and we cannot guarantee absolute security.

If a security incident affects personal data, Kssmi assesses it and provides any notification required by applicable law.
