Мо мақсад дорем, ки маълумоти шахсиро танҳо то он даме, ки барои мақсаде, ки он ҷамъ оварда шудааст, оқилона зарур аст, аз ҷумла тиҷорати қонунӣ, амният, муҳосибот ва талаботи қонунӣ нигоҳ дорем. Давраҳои нашршуда бояд ба равандҳои зиндаи несткунӣ ва нусхабардорӣ мувофиқат кунанд.

### Мӯҳлатҳои нигоҳдорӣ

Ба системаҳои вебсайте, ки дар ин огоҳӣ тавсиф шудаанд, мӯҳлатҳо ва меъёрҳои зерин татбиқ мешаванд:

| Маълумот | Татбиқи ҷорӣ ё давраи пешниҳодшуда |
| --- | --- |
| Сафари махзани VJT асосёфта ба розигӣ | нобаёнӣ 90 рӯз |
| Нияти рӯйдоди тамоси WhatsApp/почтаи электронӣ | нобаёнӣ 90 рӯз |
| Натиҷаи дархости тасдиқшудаи сервер | нобаёнӣ 730 рӯз |
| Кукии меҳмони VJT | То тақрибан 365 рӯз |
| ID-и меҳмони VJT дар нигоҳдории маҳаллӣ | То бозхонди розигии таҳлилӣ ё тоза кардани захираи браузер |
| Гузориши JSON-и почтаи электронии дархост | 1,000 сабти охирин ба ҷои давраи асосёфта ба вақт |
| Файлҳои бозгашти маҳдудияти суръат | Ҳисобкунакҳои мӯҳлаташон гузашта ҳангоми истифодаи дубора филтр карда мешаванд, аммо файлҳои кӯҳна метавонанд боқӣ монанд |
| Қуттии почтаи электронӣ ва мукотибаи тиҷоратӣ | Дар давоми дархост ё муносибатҳои тиҷоратӣ ва баъдан мувофиқи талаботи шартномавӣ, муҳосибӣ, баҳс ва ҳуқуқӣ |
| Гузоришҳои сервер ва нусхаҳои эҳтиётӣ | То ҳадде ки барои таҳқиқоти амниятӣ ва гардиши нусхаҳои эҳтиётӣ лозим аст; баъдан нест ё рӯйнавис мешавад |

Маълумот метавонад дарозтар нигоҳ дошта шавад, агар он барои ӯҳдадории қонунӣ, баҳс, тафтиши қаллобӣ ё даъвои ҳуқуқӣ оқилона зарур бошад.

### Амният

Мо чораҳои техникӣ ва ташкилиро истифода мебарем, ки барои ҳифзи маълумоти шахсӣ аз дастрасии беиҷозат, гум шудан, сӯиистифода, тағйир додан ё ифшо кардан пешбинӣ шудаанд. Чораҳо метавонанд назорати дастрасӣ, интерфейсҳои муҳофизатшудаи маъмурӣ, рамзгузории нақлиёт, маҳдуд кардани суръат, санҷиши амният, нигоҳдории маҳдуди сервер ва нигоҳдории системаро дар бар гиранд.

Ҳеҷ як усули интиқол ё нигоҳдорӣ комилан бехатар нест.

Агар ҳодисаи амниятӣ ба маълумоти шахсӣ таъсир расонад, Kssmi бояд тартиби арзёбӣ ва огоҳии дохилиро, ки талаботи қонунии амалкунандаро инъикос мекунад, риоя кунад.
