Маълумоти шахсиро танҳо ба андозаи зарурати оқилонаи мақсади ҷамъоварӣ, аз ҷумла ниёзҳои қонунии тиҷоратӣ, амният, ҳисобдорӣ ва ҳуқуқӣ нигоҳ медорем.

### Мӯҳлатҳои нигоҳдорӣ

Ба системаҳои вебсайте, ки дар ин огоҳӣ тавсиф шудаанд, мӯҳлатҳо ва меъёрҳои зерин татбиқ мешаванд:

| Маълумот | Муҳлат ё меъёри нигоҳдорӣ |
| --- | --- |
| Сафари махзани VJT асосёфта ба розигӣ | нобаёнӣ 90 рӯз |
| Нияти рӯйдоди тамоси WhatsApp/почтаи электронӣ | нобаёнӣ 90 рӯз |
| Натиҷаи дархости тасдиқшудаи сервер | нобаёнӣ 730 рӯз |
| Кукии меҳмони VJT | То тақрибан 365 рӯз |
| ID-и меҳмони VJT дар нигоҳдории маҳаллӣ | То бозхонди розигии таҳлилӣ ё тоза кардани захираи браузер |
| Гузориши JSON-и почтаи электронии дархост | 730 рӯз; 1,000 сабти охирин ба ҷои давраи асосёфта ба вақт |
| Файлҳои бозгашти маҳдудияти суръат | Дар давраи амниятии фаъол ва поксозии техникии баъдӣ |
| Қуттии почтаи электронӣ ва мукотибаи тиҷоратӣ | Дар давоми дархост ё муносибатҳои тиҷоратӣ ва баъдан мувофиқи талаботи шартномавӣ, муҳосибӣ, баҳс ва ҳуқуқӣ |
| Гузоришҳои сервер ва нусхаҳои эҳтиётӣ | То ҳадде ки барои таҳқиқоти амниятӣ ва гардиши нусхаҳои эҳтиётӣ лозим аст; баъдан нест ё рӯйнавис мешавад |
| Нусхаҳои дархост дар навбат | 30 рӯз |
| Кушоданҳои инфиродии пайвандҳои кӯтоҳ | 90 рӯз |
| Далелҳои ҷудогонаи ризоияти дархост | 730 рӯз |

Маълумот метавонад дарозтар нигоҳ дошта шавад, агар он барои ӯҳдадории қонунӣ, баҳс, тафтиши қаллобӣ ё даъвои ҳуқуқӣ оқилона зарур бошад.

Сабти ризоият ID ва хеши матни огоҳӣ, забон, нусха ва вақти қабули серверро дорад. Сабтҳои расонидан ва далелҳо то 730 рӯз ва дар ҳадди 1 000 сабт нигоҳ дошта мешаванд. Нусхаҳои навбат пас аз муваффақияти ҳар ду ирсол нест мешаванд; нусхаҳои ноком баъди 30 рӯзи қабул муҳлаташон мегузарад. Кушоданҳои инфиродии пайванд баъди 90 рӯз муҳлаташон мегузарад; худи пайванд ва ишораҳои паҳнкунӣ ба мақсади давомдори тиҷоратӣ ва дархости несткунӣ вобастаанд. Поксозӣ тавассути нигоҳдорӣ ва амалиёти баъдӣ аст. Кори банд ва сабти хонданашаванда барои санҷиши бехатар мавқуф ё нишонгузорӣ мешаванд. Почта ва нусхаҳо меъёрҳои ҷудогонаи болоро доранд. Баргардонидан ва нобудсозӣ тибқи NDA ва истисноҳост; муҳлати махфият иҷозати нигоҳдории ҳама маълумот нест.

### Амният

Мо чораҳои техникӣ ва ташкилиро истифода мебарем, ки барои ҳифзи маълумоти шахсӣ аз дастрасии беиҷозат, гум шудан, сӯиистифода, тағйир додан ё ифшо кардан пешбинӣ шудаанд. Чораҳо метавонанд назорати дастрасӣ, интерфейсҳои муҳофизатшудаи маъмурӣ, рамзгузории нақлиёт, маҳдуд кардани суръат, санҷиши амният, нигоҳдории маҳдуди сервер ва нигоҳдории системаро дар бар гиранд.

Ҳеҷ як усули интиқол ё нигоҳдорӣ комилан бехатар нест.

Агар ҳодисаи амниятӣ ба маълумоти шахсӣ таъсир расонад, Kssmi онро арзёбӣ намуда, огоҳиҳои талабкардаи қонунро медиҳад.
