我们仅在实现收集目的以及满足合理的业务、安全、会计和法律要求所必需的期限内保留个人数据。

### 保留期限

以下期限和标准适用于本声明中说明的网站系统：

| 数据 | 保留期限或标准 |
| --- | --- |
| 基于同意的 VJT 数据库旅程 | 通常为 90 天，受配置的保留设置和自动清理机制约束 |
| WhatsApp/电子邮件联系事件意图 | 通常为 90 天 |
| 服务器确认的询盘结果 | 通常为 730 天 |
| 浏览器中的 VJT 访问者 ID | Cookie 最长约 365 天；本地存储副本保留至撤回分析同意或清除浏览器存储 |
| 询盘电子邮件 JSON 日志 | 730 天; 最多保留最近 1,000 条投递记录 |
| 安全和速率限制计数器 | 在有效安全窗口及后续技术清理所需期间保留 |
| 电子邮件邮箱和业务信件 | 在询盘或业务关系存续期间保留，其后按合同、会计、争议处理和法律义务所需期限保留 |
| 服务器日志和备份 | 按安全调查和备份轮换需要保留，不再需要时删除或覆盖 |
| 排队询盘副本 | 30 天 |
| 逐条短链打开记录 | 90 天 |
| 独立询盘同意凭据 | 730 天 |

在履行法律义务、处理争议、调查欺诈或提出/应对法律请求所合理必要时，数据可能保留更长时间；不再需要时，也可能更早删除或匿名化。

已接受询盘的同意记录包含告知编号、告知文本哈希、语言、隐私声明版本及服务端接收时间。投递日志及其中的同意证据最长保存 730 天，同时受 1000 条记录上限约束。两个发送步骤成功后移除队列副本；未成功的队列副本在接收后 30 天到期。逐条短链打开记录在 90 天后到期；短链本身及分发标记仍按持续业务目的和删除请求标准管理。清理由维护任务及后续相关操作执行；正在处理的任务和不可读记录会延期或标记人工核查，避免盲目删除。邮箱和备份按上文各自标准处理。NDA 下的返还或销毁依该 NDA 及其保留例外执行，保密期限本身不是保留全部资料的许可。

### 安全

我们采用技术和组织措施来保护个人数据免受未经授权的访问、丢失、滥用、更改或披露。措施可能包括访问控制、受保护的管理界面、传输加密、速率限制、安全验证、受限的服务器存储和系统维护。

任何传输或存储方式都不是绝对安全的，我们无法保证绝对安全。

如果安全事件影响个人数据，可米 将进行评估，并按照适用法律作出必要通知。
