個人データは収集目的に合理的に必要な期間のみ保存します。これには正当な業務、安全、会計および法的要件が含まれます。

### 保存期間

本通知に記載されたウェブサイトシステムには、次の期間と基準が適用されます。

| データ | 保存期間または判断基準 |
| --- | --- |
| 同意に基づくVJTデータベースジャーニー | デフォルト90日 |
| WhatsApp/電子メールの連絡先イベントの意図 | デフォルト90日 |
| サーバーで確認された問い合わせ結果 | デフォルト730日 |
| VJT訪問者Cookie | 最大約365日 |
| ローカルストレージ内のVJT訪問者ID | 分析への同意が撤回されるか、ブラウザストレージが消去されるまで |
| 問い合わせメールのJSONログ | 730 日; 期間ではなく最新の1,000件の記録 |
| レート制限フォールバックファイル | 有効な安全管理期間およびその後の技術的整理の間 |
| 電子メールのメールボックスとビジネス通信 | 問い合わせまたは取引関係の継続中、およびその後は契約、会計、紛争対応、法的義務に必要な期間 |
| サーバーログとバックアップ | セキュリティ調査およびバックアップローテーションに必要な期間。その後、削除または上書きされます |
| 問い合わせキューのコピー | 30 日 |
| 短縮リンクの個別開封記録 | 90 日 |
| 独立した問い合わせ同意記録 | 730 日 |

法的義務、紛争、詐欺の調査、または法的請求のために合理的に必要な場合、データはより長く保持される場合があります。

受理した同意記録には通知ID、通知文のハッシュ、言語、版およびサーバー受信時刻を含みます。配信ログと同意証拠は最長730日かつ1,000件以内で保存します。キューのコピーは両送信成功後に削除し、未成功分は受付30日後に期限を迎えます。短縮リンクの個別開封記録は90日後に期限を迎え、リンク本体と配布参照情報には継続的業務目的と削除請求の基準を適用します。保守および関連する後続処理で整理します。処理中の作業や読取不能な記録は安全確認のため延期または要確認にします。メールとバックアップには上記別基準を適用します。NDA上の返還・破棄は例外も含めNDAに従い、秘密保持期間だけでは全データ保存を許可しません。

### セキュリティ

当社は、不正アクセス、紛失、誤用、改ざん、または開示から個人データを保護することを目的とした技術的および組織的な対策を使用しています。対策には、アクセス制御、保護された管理インターフェース、転送暗号化、レート制限、セキュリティ検証、制限されたサーバーストレージ、およびシステムメンテナンスが含まれる場合があります。

伝送または保存の方法で完全に安全なものはありません。

安全上の事故が個人データに影響する場合、Kssmiは評価し、適用法が求める通知を行います。
