Miriamo a conservare i dati personali solo per il tempo ragionevolmente necessario allo scopo per cui sono stati raccolti, compresi i requisiti aziendali, di sicurezza, contabili e legali legittimi. I periodi pubblicati devono corrispondere ai processi reali di eliminazione e backup.

### Periodi di conservazione

Ai sistemi del sito descritti nella presente informativa si applicano i seguenti periodi e criteri:

| Dati | Implementazione attuale o periodo proposto |
| --- | --- |
| Percorso del database VJT basato sul consenso | predefinito 90 giorni |
| Intento evento di contatto WhatsApp/e-mail | predefinito 90 giorni |
| Esito della richiesta confermato dal server | predefinito 730 giorni |
| Cookie visitatore VJT | Fino a circa 365 giorni |
| ID visitatore VJT nell'archiviazione locale | Fino alla revoca del consenso alle analisi o alla cancellazione della memoria del browser |
| Log JSON dell'e-mail di richiesta | Ultimi 1.000 record anziché un periodo basato sul tempo |
| File di fallback del limite di frequenza | I contatori scaduti vengono filtrati se riutilizzati, ma potrebbero rimanere vecchi file |
| Casella di posta elettronica e corrispondenza aziendale | Per la durata della richiesta o del rapporto commerciale e successivamente secondo le esigenze contrattuali, contabili, di gestione delle controversie e legali |
| Log e backup del server | Per quanto necessario alle indagini di sicurezza e alla rotazione dei backup; successivamente eliminati o sovrascritti |

I dati possono essere conservati più a lungo laddove sia ragionevolmente necessario per un obbligo legale, una controversia, un'indagine per frode o una rivendicazione legale.

### Sicurezza

Utilizziamo misure tecniche e organizzative intese a proteggere i dati personali da accessi non autorizzati, perdita, uso improprio, alterazione o divulgazione. Tali misure possono includere controlli degli accessi, interfacce amministrative protette, crittografia del trasporto, limitazione della frequenza (rate limiting), verifica di sicurezza, archiviazione limitata sul server e manutenzione del sistema.

Nessun metodo di trasmissione o archiviazione è completamente sicuro.

Se un incidente di sicurezza interessa i dati personali, Kssmi deve seguire una procedura di valutazione e notifica interna che rifletta i requisiti legali applicabili.
