Conserviamo i dati personali solo per il tempo ragionevolmente necessario alla finalità della raccolta, compresi gli obblighi commerciali legittimi, di sicurezza, contabili e legali.

### Periodi di conservazione

Ai sistemi del sito descritti nella presente informativa si applicano i seguenti periodi e criteri:

| Dati | Periodo o criterio di conservazione |
| --- | --- |
| Percorso del database VJT basato sul consenso | predefinito 90 giorni |
| Intento evento di contatto WhatsApp/e-mail | predefinito 90 giorni |
| Esito della richiesta confermato dal server | predefinito 730 giorni |
| Cookie visitatore VJT | Fino a circa 365 giorni |
| ID visitatore VJT nell'archiviazione locale | Fino alla revoca del consenso alle analisi o alla cancellazione della memoria del browser |
| Log JSON dell'e-mail di richiesta | 730 giorni; Ultimi 1.000 record anziché un periodo basato sul tempo |
| File di fallback del limite di frequenza | Per la finestra di sicurezza attiva e la successiva pulizia tecnica |
| Casella di posta elettronica e corrispondenza aziendale | Per la durata della richiesta o del rapporto commerciale e successivamente secondo le esigenze contrattuali, contabili, di gestione delle controversie e legali |
| Log e backup del server | Per quanto necessario alle indagini di sicurezza e alla rotazione dei backup; successivamente eliminati o sovrascritti |
| Copie delle richieste in coda | 30 giorni |
| Singole aperture dei link brevi | 90 giorni |
| Ricevute di consenso separate | 730 giorni |

I dati possono essere conservati più a lungo laddove sia ragionevolmente necessario per un obbligo legale, una controversia, un'indagine per frode o una rivendicazione legale.

Il consenso registrato include ID e hash del testo dell'informativa, lingua, versione e ora di ricezione del server. I log di consegna e le prove di consenso durano fino a 730 giorni, anche entro il limite di 1.000 record. Le copie in coda riuscite vengono rimosse dopo entrambi gli invii; quelle non riuscite scadono 30 giorni dopo l'accettazione. Le singole aperture dei link scadono dopo 90 giorni; link e riferimenti di distribuzione seguono i criteri di finalità commerciale e richiesta di cancellazione. La pulizia avviene tramite manutenzione e operazioni successive pertinenti. Lavori occupati e dati illeggibili vengono rinviati o segnalati per verifica sicura. Posta e backup seguono i criteri distinti sopra indicati. Restituzione e distruzione seguono l'NDA e le sue eccezioni; la durata di riservatezza non autorizza a conservare tutti i dati.

### Sicurezza

Utilizziamo misure tecniche e organizzative intese a proteggere i dati personali da accessi non autorizzati, perdita, uso improprio, alterazione o divulgazione. Tali misure possono includere controlli degli accessi, interfacce amministrative protette, crittografia del trasporto, limitazione della frequenza (rate limiting), verifica di sicurezza, archiviazione limitata sul server e manutenzione del sistema.

Nessun metodo di trasmissione o archiviazione è completamente sicuro.

Se un incidente di sicurezza coinvolge dati personali, Kssmi lo valuta ed effettua le notifiche richieste dalla legge applicabile.
