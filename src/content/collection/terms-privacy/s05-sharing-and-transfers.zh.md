我们仅在为了本声明中所述目的而合理必要、法律要求或与确立、行使或捍卫法律索赔相关的情况下，才会披露个人数据。

### 服务提供商和接收方

在运营、保护、通过本网站进行沟通和衡量本网站合理必要的情况下，我们可能会使用以下类别的接收方和服务提供商：

| 接收方或服务类别 | 角色或功能 | 可能涉及的数据 |
| --- | --- | --- |
| 云托管和基础设施提供商 | 网站和服务器托管、存储、备份和系统可用性 | 技术请求数据、服务器日志和存储的网站记录 |
| 内容交付和安全提供商 | 内容交付、代理服务、安全检查和防止滥用 | IP 地址、请求元数据、安全信号和技术日志 |
| 分析和广告提供商 | 基于同意的衡量、归因和广告功能 | 同意状态、标识符、页面事件和营销活动信息 |
| 通信平台提供商 | 用户有意选择的通信服务 | 帐户标识符、消息内容和相关的通信元数据 |
| 媒体交付提供商 | 网站视频或其他媒体的交付和性能 | IP 地址、设备/浏览器信息和媒体请求数据 |
| 大致位置服务提供商 | 用于询盘路由或安全的国家级或区域查找 | IP 地址和派生的大致位置 |
| 电子邮件、备份、监控和维护提供商 | 业务通信、弹性、故障排除和系统运行 | 询盘数据、信件、技术日志和备份副本（适用时） |

在存在适当的法律依据和保护措施的情况下，我们还可能与专业顾问、监管机构、执法机构或企业交易方共享相关信息。

### 国际数据转移

Kssmi 在中国设立。用户通过网站或其主动选择的通信渠道直接提交的信息，可能因此在中国处理。部分服务提供商也可能在用户所在国家或欧洲经济区以外处理信息。

在 GDPR 第五章适用于控制者或处理者进行的数据转移时，该转移必须采用与具体情况相适应的合法机制，例如充分性决定、适用的欧盟委员会标准合同条款，或法律允许的其他保障措施或例外。在适当情况下，我们会采取补充的技术和组织措施。您可通过 **privacy [at] kssmi [dot] com** 请求与您的数据有关的保障措施信息，但依法应保密的内容除外。
