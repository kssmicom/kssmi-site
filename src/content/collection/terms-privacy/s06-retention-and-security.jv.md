Kita nyimpen data pribadi mung suwene sing wajar dibutuhake kanggo tujuan pangumpulan, kalebu kabutuhan bisnis sah, keamanan, akuntansi lan hukum.

### Wektu panyimpenan

Wektu lan kritéria ing ngisor iki ditrapake kanggo sistem situs web sing diterangake ing kabar iki:

| Data | Wektu utawa kritéria panyimpenan |
| --- | --- |
| Perjalanan database VJT adhedhasar idin | gawan 90 dina |
| Niat acara kontak WhatsApp/email | gawan 90 dina |
| Hasil pitakon sing dikonfirmasi server | gawan 730 dina |
| Cookie pengunjung VJT | Nganti udakara 365 dina |
| ID pengunjung VJT ing panyimpenan lokal | Nganti idin analitik ditarik utawa panyimpenan browser dibusak |
| Log JSON email pitakon | 730 dina; 1.000 rekaman paling anyar tinimbang periode basis wektu |
| File panggantos watesan wektu | Sajrone jendhela keamanan aktif lan reresik teknis sabanjure |
| Kothak layang email lan korespondensi bisnis | Sajrone pitakon utawa hubungan bisnis lan sakwise miturut kabutuhan kontrak, akuntansi, perselisihan lan kewajiban hukum |
| Log server lan serep | Miturut kabutuhan investigasi keamanan lan rotasi serep; banjur dibusak utawa ditindhes |
| Salinan pitakon ing antrean | 30 dina |
| Cathetan pambukaan pranala cekak individu | 90 dina |
| Bukti idin pitakon kapisah | 730 dina |

Data bisa uga disimpen luwih suwe yen pancen perlu kanggo kewajiban hukum, perselisihan, investigasi penipuan utawa pratelan hukum.

Cathetan idin ngemot ID lan hash teks kabar, basa, versi lan wektu ditampa server. Log pangiriman lan bukti idin disimpen nganti 730 dina lan diwatesi 1.000 cathetan. Salinan antrean dibusak sawise loro pangiriman sukses; sing gagal kadaluwarsa 30 dina sawise ditampa. Cathetan pambukaan pranala individu kadaluwarsa 90 dina; pranala lan referensi distribusi manut tujuan bisnis sing isih ana lan panjaluk mbusak. Reresik liwat pangopènan lan operasi sabanjure. Tugas sibuk lan cathetan ora bisa diwaca ditundha utawa ditandhani kanggo dipriksa kanthi aman. Email lan serep manut kritéria kapisah ing ndhuwur. Mbalekake lan ngrusak manut NDA lan pangecualiane; wektu kerahasiaan dudu idin nyimpen kabeh data.

### Keamanan

Kita nggunakake langkah-langkah teknis lan organisasi sing dimaksudake kanggo nglindhungi data pribadhi saka akses, mundhut, nyalahi panggunaan, pangowahan utawa pambocoran sing ora sah. Langkah-langkah kasebut bisa uga kalebu kontrol akses, antarmuka administratif sing dilindhungi, enkripsi transportasi, watesan tingkat, verifikasi keamanan, panyimpenan server sing diwatesi lan pangopènan sistem.

Ora ana metode transmisi utawa panyimpenan sing bener-bener aman.

Yen kedadeyan keamanan mengaruhi data pribadi, Kssmi ngevaluasi lan menehi kabar sing diwajibake hukum.
